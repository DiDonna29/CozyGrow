# **App Name**: CozyGrow Calendar

## Core Features:

- Interactive Season Calendar: Allows users to select or navigate through different seasons (e.g., Spring, Summer, Autumn, Winter) to view seasonal information.
- Optimal Crop Display: Presents a list of crops that are optimal for planting or harvesting in the currently selected season, along with basic details.
- Daily Farm Task List: Enables users to add, manage, mark as complete, and delete personalized daily farming tasks.
- Multi-language Toggle (EN/ES): A dedicated UI component to switch the application's entire user interface text between English and Spanish.
- Dynamic Theme Switching: A toggle switch that instantly changes the app's visual theme between a provided 'sunny' light mode and a 'cozy nocturnal' dark mode.

## Style Guidelines:

- Light Theme Background: A warm, soft cream (#FFF8E1) to evoke a sunny, expansive daytime feel. Primary elements and card backgrounds: A brighter, cheerful amber-yellow (#FFE082). Accent elements and call-to-actions: A vibrant, clear amber-orange (#FF8F00).
- Dark Theme Background: A deep, rich chocolate brown (#3E2723) to reflect a cozy, wooden cabin night ambiance. Primary elements and card backgrounds: A slightly lighter, earthy brown (#4E342E). Accent elements and call-to-actions: A bright, glowing orange (#FFA000) for contrast.
- Headline font: 'Alegreya' (serif) for an elegant, intellectual, and cultivated feel. Body font: 'Inter' (sans-serif) for clean, objective, and highly readable text in longer passages and task descriptions.
- Utilize warm, inviting, and somewhat illustrative icons. Focus on elements related to nature, farming tools, specific crops, and seasonal representations (sun, moon, rain, snowflakes).
- Implement a clear, card-based layout to visually separate content like seasonal crops and daily tasks. Ensure ample padding and intuitive grouping for a 'cozy' and organized feel, facilitating easy navigation between sections.
- Incorporate subtle and smooth transitions for UI changes, such as theme switching, season navigation, and task completion. Animations should be gentle, contributing to a calm and immersive user experience rather than being distracting.
